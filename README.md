# SNAKE BROS. 🐍🍄

Змейка в духе классического платформера: монеты, грибы, звезда неуязвимости, варп-трубы, частицы, screen shake и полностью синтезированный чиптюн-саундтрек на Web Audio API.

**Играть:** https://allgrit.github.io/snake-bros/

## Управление

| Клавиша | Действие |
|---|---|
| ← ↑ ↓ → / WASD | движение |
| ENTER | старт / рестарт |
| P | пауза |
| M | звук вкл/выкл |

На телефоне: свайпы по полю или экранный D-pad (крестовина + OK), вёрстка адаптируется под portrait и landscape.

## Механика

- **Монеты** — +100 очков, рост змейки. Каждые 8 монет — «COURSE CLEAR» и новый мир с кирпичами.
- **Гриб** — +500 очков, +3 сегмента.
- **Звезда** — 6 секунд радужной неуязвимости: ломает кирпичи и позволяет проходить сквозь себя.
- **1-UP гриб** — дополнительная жизнь.
- **Трубы** — телепортируют на противоположный край поля.

Один самодостаточный `index.html` — без зависимостей и сборки.
